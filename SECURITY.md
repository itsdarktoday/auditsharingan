# Security policy

AuditSharingan is maintained by [@itsdarktoday](https://github.com/itsdarktoday)
and [@0xscarfac3](https://github.com/0xscarfac3).

AuditSharingan is an audit workflow and does not guarantee that a protocol is
secure. Treat every generated lead as unvalidated until the evidence chain in
`SKILL.md` is complete.

## Reporting a problem in this repository

For a vulnerability in the engine, scripts, schemas, or skill instructions,
use a private GitHub Security Advisory for the repository when that feature is
available. If it is not enabled, contact the repository maintainers privately
before opening a public issue. Include the affected path, a minimal
reproduction, impact, and any proposed mitigation. Do not include private
protocol source, private keys, RPC credentials, or unpublished exploit details
in a public issue.

## Auditing a target

Run the workflow only against code and environments you are authorized to
review. Do not provide live private keys, send transactions, or use a live
deployment unless the owner has explicitly authorized that action and the
scope records it.
