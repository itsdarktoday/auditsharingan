# External regression notes

The external fixture set contains X01–X18: six price-manipulation examples,
three EVM benign controls, seven Solana/Rust cases, and two Move cases. The
2026-08-13 run recorded the expected class for all listed cases, with
trace-level evidence and no live deployment validation.

This is a historical, author-run snapshot. It is not a blind or independently
replicated benchmark. Use `evals/score.py` with an explicit prediction file to
recompute the result.
